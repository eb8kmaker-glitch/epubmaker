# Sample files for EPUB conversion testing

- **sample.md** – Markdown sample with headings (h1–h3) for TOC testing.
- **sample.html** – HTML sample with the same structure.
- **sample.pdf** – Add a PDF file here manually to test PDF → HTML → EPUB. Any small PDF with text content will work.

Use these on the `/convert` page to verify DOCX, TXT, PDF, HTML, and MD conversion.
