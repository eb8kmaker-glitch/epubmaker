표지는 독자가 처음 보는 것입니다. 올바른 크기를 설정하면 6인치 전자 잉크 화면부터 데스크탑 독서 앱까지 모든 플랫폼에서 선명하고 전문적으로 보입니다.

## 범용 안전 크기

어디서나 잘 작동하는 단 하나의 크기를 원한다면:

**1,600 × 2,400 px**, **72–96 DPI**, **JPEG**로 저장(품질 80–90%)

이 크기는 책 표지의 업계 표준인 2:3 비율(세로)을 제공합니다.

## 플랫폼별 요구 사항

### Amazon Kindle (KDP)

| 항목 | 값 |
|---|---|
| 권장 | 2,560 × 1,600 px |
| 최소 | 긴 쪽 1,000 px 이상 |
| 비율 | 1.6:1 (가로) 또는 1:1.6 (세로) |
| 형식 | JPEG 또는 TIFF |
| 최대 파일 크기 | 50 MB |

> 참고: KDP의 권장 크기는 특이합니다 — Kindle 스토어의 가로 방향 썸네일 뷰를 우선시합니다. 세로 방향 책에는 **1,600 × 2,560 px**를 사용하세요.

### Apple Books

| 최소 | 1,400 × 1,873 px |
| 비율 | 2:3 |
| 형식 | JPEG 또는 PNG |

| 형식 | JPEG 또는 PNG |

## 비율 설명

**비율(Aspect Ratio)**은 너비와 높이의 관계입니다.

- **2:3** — 대부분의 전자책 표지 표준. 1,600 × 2,400 px 이미지가 2:3 비율입니다.
- **1:1.6** — Amazon의 선호 비율. 2:3과 동일하지만 다르게 명시됩니다.
- **1:1** — 정사각형 표지. 책에서는 거의 사용되지 않습니다.

표지를 올바른 비율로 변환하려면 이미지 편집기에서 자르세요: Photoshop, Canva, GIMP, 또는 Affinity Photo.

## 색상 모드: RGB vs CMYK

전자책 표지에는 항상 **RGB**를 사용하세요. CMYK는 인쇄용입니다. EPUB에 삽입되는 JPEG 파일은 항상 RGB 모드여야 합니다.

## 파일 형식: JPEG vs PNG

| | JPEG | PNG |
|---|---|---|
| 최적 용도 | 사진, 그라디언트 | 텍스트 위주, 단색 아트 |
| 파일 크기 | 작음 | 큼 |
| 투명도 | 없음 | 있음 |
| 품질 손실 | 미미함(80% 이상) | 없음 |

사진 요소가 있는 대부분의 표지에는 **JPEG 80–85% 품질**이 최선입니다. 단색이나 픽셀 완벽도가 필요한 텍스트가 있는 경우에만 PNG가 더 좋습니다.

## EPUBMaker에서 표지 삽입하기

EPUBMaker로 변환할 때:

1. JPEG 또는 PNG로 표지 준비, 1,600 × 2,400 px
2. 변환 설정에서 "표지 이미지"를 클릭하고 파일 업로드
3. EPUBMaker가 EPUB 표지로 삽입하고 올바른 메타데이터 설정
4. 표지가 독서 앱과 전자책 스토어 목록에 표시됨

표지는 EPUB의 `cover-image` 메타데이터 항목으로도, 첫 페이지로도 삽입되어 모든 주요 플랫폼 요구 사항을 충족합니다.

## 흔한 실수 피하기

- **너무 작은 크기:** 어떤 방향으로든 1,000 px 미만의 표지는 레티나 디스플레이에서 흐릿하게 보임
- **잘못된 비율:** 세로 형식 책에 가로 표지는 비전문적으로 보임
- **CMYK 색상 모드:** 일부 독서 앱에서 색상 왜곡 또는 오류 발생
- **사진에 PNG 사용:** 불필요하게 큰 파일 크기
- **업데이트 忘却:** 표지 수정 시 다시 업로드하고 EPUB 재변환 필요
