원고를 완성하고 나면 첫 번째 결정은 형식입니다: **EPUB인가, PDF인가?**

두 형식 모두 디지털 배포에 널리 사용되지만, 목적이 크게 다릅니다. 차이를 이해하면 올바른 형식을 선택하거나, 경우에 따라 두 형식 모두 제작해야 한다는 것을 알 수 있습니다.

## EPUB이란?

EPUB(Electronic Publication)은 W3C가 관리하는 오픈 표준 형식입니다. 대부분의 현대 전자책 리더와 앱의 기본 형식입니다:

- Apple Books
- Google Play Books
- 코보(Kobo)
- Adobe Digital Editions
- Moon+ Reader (안드로이드)

EPUB 파일은 본질적으로 HTML, CSS, 이미지 파일을 담은 ZIP 압축 파일입니다 — 미니 웹사이트처럼 구성되어 있습니다. 이 덕분에 어떤 화면 크기에서도 텍스트가 **리플로우**됩니다.

## PDF란?

PDF(Portable Document Format)는 어떤 기기나 프린터에서도 정확한 시각적 레이아웃을 보존하도록 Adobe가 설계했습니다. PDF는 항상 동일하게 보입니다 — 폰트, 여백, 페이지 나눔이 고정됩니다.

레이아웃 정확성이 독서 편의성보다 중요할 때 PDF가 적합합니다.

## 주요 차이점

### 1. 리플로우(Reflow)

| 기능 | EPUB | PDF |
|---|---|---|
| 글꼴 크기 조절 | 가능 | 불가 |
| 줄 간격 조절 | 가능 | 불가 |
| 세로/가로 전환 시 재배치 | 가능 | 불가 |
| 고정 페이지 레이아웃 | 없음 | 있음 |

EPUB은 독자의 선호에 맞게 조정됩니다. PDF는 그렇지 않습니다. 6인치 전자책 리더에서 A4 용지 기준으로 포맷된 PDF는 너무 작거나 가로 스크롤이 필요할 수 있습니다.

### 2. 기기 호환성

**EPUB**은 다음에서 기본 지원됩니다:
- 전자 잉크 리더(코보, 킨들은 Send-to-Kindle 변환 필요)
- iOS 및 안드로이드 독서 앱
- Calibre, Adobe Digital Editions 같은 데스크탑 앱

**PDF**는 다음에서 지원됩니다:
- PDF 뷰어가 있는 모든 기기
- 그러나 소형 전자 잉크 화면에서는 불편

> **참고:** Amazon Kindle은 EPUB을 기본 지원하지 않습니다. MOBI/KFX로 변환하거나 Amazon의 Send-to-Kindle 서비스(EPUB 자동 변환)를 사용해야 합니다.

### 3. 접근성

EPUB 3는 강력한 내장 접근성 기능을 갖추고 있습니다:
- 스크린 리더를 위한 시맨틱 HTML 구조
- 올바른 제목 계층 구조
- 이미지 대체 텍스트 지원
- ARIA 랜드마크

PDF는 접근성 태그가 특별히 추가되지 않으면 접근성이 제한적입니다.

### 4. 편집 가능성

EPUB은 배포 후 업데이트가 더 쉽습니다 — ZIP을 열고 HTML/CSS를 편집한 후 다시 패키징할 수 있습니다. PDF는 원본 제작 소프트웨어가 있어야 깨끗하게 편집됩니다.

### 5. DRM과 배포

두 형식 모두 DRM(디지털 저작권 관리)을 지원하지만, EPUB이 대부분의 전자책 소매점 표준입니다. Amazon은 자체 독점 형식(KFX)을 사용하지만, Amazon을 제외한 주요 소매점 — Apple, 코보, Google — 은 모두 EPUB을 사용합니다.

## EPUB을 선택해야 할 때

다음과 같은 경우 EPUB을 선택하세요:
- 전자책 소매점(Apple Books, 코보, Google Play)을 통해 배포할 때
- 책이 주로 텍스트 기반일 때(소설, 논픽션, 에세이)
- 독자 경험과 접근성이 중요할 때
- 다양한 화면 크기에 맞는 리플로우 텍스트가 필요할 때

## PDF를 선택해야 할 때

다음과 같은 경우 PDF를 선택하세요:
- 레이아웃이 중요할 때(요리책, 사진집, 복잡한 그림이 있는 교과서)
- 주문형 인쇄(Print-on-Demand) 서비스에 배포할 때
- 독자가 주로 데스크탑이나 대형 태블릿에서 읽을 때
- 정확한 타이포그래피와 디자인을 보존해야 할 때

## 두 형식 모두 제작해야 할까?

대부분의 작가에게 **그렇습니다**. 일반적인 워크플로우는:

1. DOCX 또는 마크다운으로 작성
2. 전자책 배포를 위해 EPUB으로 변환
3. 주문형 인쇄 또는 저자 웹사이트 다운로드를 위해 PDF로 변환

EPUBMaker는 2단계를 처리합니다 — DOCX 또는 TXT 파일을 표준 준수 EPUB으로 수 초 만에 변환합니다.

## 요약

| | EPUB | PDF |
|---|---|---|
| 최적 용도 | 전자책 리더 | 고정 레이아웃, 인쇄 |
| 리플로우 | 가능 | 불가 |
| 킨들 기본 지원 | 아니요(변환 필요) | 아니요(변환 필요) |
| 접근성 | 우수 | 제한적 |
| 파일 크기 | 작음 | 더 큼 |

독서 앱과 전자책 리더를 위한 대부분의 디지털 서적에는 **EPUB이 올바른 선택**입니다. 업계가 표준화한 형식으로 — 유연하고, 접근성이 높으며, 광범위하게 지원됩니다.
